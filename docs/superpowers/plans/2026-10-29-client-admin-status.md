# 客户端与管理平台实施状态

日期：2026-10-29。对应 [需求](../specs/2026-10-29-client-admin-requirements.md) 和 [实施计划](2026-10-29-client-admin-implementation.md)。

用户已授权开始修改。本文件记录实际实现和未完成范围，不以阶段性测试代替完整验收，也不改写原需求。

## 已实现

- 独立平台服务和中文运营后台：普通用户、设备、应用、模型、售价、兑换码、赠送、钱包流水、异常核查、人工调整和版本记录。
- 邮箱验证码注册/找回密码的服务接口，密码登录和修改，会话撤销；邮件通过单独配置的 HTTPS 适配服务发送。
- 服务器保存并加密供应商密钥；普通客户目录不含密钥或上游地址。
- 后台添加/编辑模型支持获取上游模型列表、搜索和选择，覆盖 OpenAI Chat/Responses、Anthropic、Google 协议；保留手动填写，售价、限额和启用状态由管理员设置。复用已保存密钥时限制接口地址和协议不变。
- 模型表单按渠道连接信息排列，服务商可自定义，内部标识自动生成；模型名称统一支持列表选择与手动输入，显示名称可另行设置。售价保持必填，高级限额和能力默认收起，新模型初始输入/输出上限为 65536/1024、仅文本能力；编辑已有模型保留原值。
- 修复托管聊天、自动化把输入上限误当总上下文的问题：总上下文采用输入与输出上限之和，避免预留输出时重复扣减输入额度。上下文压缩失败在真实 AgentLoop 分支中给出上下文恢复建议，不再退回 API Key 检查提示。
- OpenAI Chat、Responses、Anthropic、Google 四种协议的文本、工具调用和有能力标记的图片输入转发；JSON/SSE 用量结算。
- 整数精确金额、预留和结算、兑换幂等、赠送有效期和资金来源、并发拒绝与异常待核查。
- 桌面端登录启动、账号本机目录/浏览器分区、退出进程清理、受限离线缓存、客户账户页和托管模型设置。
- 通用工作目录、插件配置、自动克隆项目及旧会话缓存按账号隔离；配置重新加载不能覆盖托管账户的数据库和工作目录。
- 学习子应用通过本机代理使用授权模型；五个入口和原有 iframe 形态保留。
- 定时任务和 Always-On 使用独立的自动化模型目录，每次模型调用重新验证权限，账单归属为 automation；不回退到聊天模型，也不修改并行聊天的运行配置。
- 聊天未授权或无模型时，本地服务仍可启动；内部禁用传输只返回拒绝，不联系服务商，也不出现在可选模型目录。
- 管理员发布更新元数据，客户端下载校验和显式安装确认。
- 独立 Docker/Compose 配置、私有初始化、SQLite 在线备份及恢复测试。
- 客户版源码启动入口 `Start-Client.cmd`：连接独立账号平台，打开真实 Electron 登录窗口；在线登录后直接进入账户页，可进入对话和学习。开发账号数据保存在 `.pilotdeck/client/user-data`。
- 中文登录、注册、找回密码与验证码冷却；账户区域独立加载，余额加载失败不会显示假零额，手动刷新同步后台模型授权。托管设置显示可用模型、账户与账单，供应商配置保持只读。
- 托管模式从桌面预加载阶段固定，首次渲染不闪现本机模型编辑器；启动页期间也检查会话撤销。
- 学习模块端口按账号保存并避让已有本地服务，重启不静默改变 iframe 的存储来源；原有 3001 本地版与客户桌面版可以同时运行。

## 尚未完成

1. 非 Token 共用收费服务：付费搜索、按张图片生成、音频/视频时长计费尚未接入，不能称为全部收费功能可用。
2. Skills、插件/MCP 内部模型请求的独立应用模型选择和账单归属尚未全面接入；聊天、学习和自动化已有各自的调用链。现有本地 API 权限校验尚未覆盖全部原生工具执行及 WebSocket 通路，后台应用开关不能宣称已完成所有细粒度能力限制。
3. 全部原有能力的真实端到端回归尚未完成，特别是 MCP/插件、电脑操作和安装后的账户切换；源码运行的真实 Electron 账号切换、聊天和学习 iframe 已通过，自动化目前通过隔离模拟服务商的真实网关测试。
4. 更新流程有用户确认和下载校验，但安装签名、真实 Windows 安装/升级、运行任务的权威检测仍需验收。当前不会自动安装或自动重启。
5. 正式服务器部署、HTTPS、邮件投递、供应商连通性、安装包存储以及 4 核 4 GB 压测尚无真实环境验证。
6. 商业分发授权仍按需求第 17 节处理，未擅自删除或更换模块。

## 当前运行方式

本机管理平台通常为 `http://127.0.0.1:3100`，实际以 `.pilotdeck/platform/service.json` 为准。初始开发管理员凭据在 `.pilotdeck/platform/administrator.txt`，不写入本文件。

双击仓库根目录 `Start-Client.cmd` 打开客户版桌面窗口，默认连接 `http://127.0.0.1:3100`；需先启动平台。登录使用后台创建的普通用户，管理员账号不能作为客户登录。自助注册/找回密码仍需配置真实邮件服务；真实 AI 调用需后台配置并开放模型。

原 `localhost:3001` Web 部署保持本地模式；客户版是独立桌面窗口，不通过修改旧浏览器账号来切换。当前已启动源码运行的客户版，尚未生成可分发的 Windows 安装包。

操作与部署步骤见 [平台说明](../../../ui/platform/README.md)。
